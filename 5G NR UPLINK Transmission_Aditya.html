Eighteen stages, one causal chain

Nothing in the uplink “just happens”. Each stage is a direct consequence of the one before it — hover or click a stage to see what it unlocks.

Stages 1–2 · Silicon wake-up

Power rails are sequenced core → DRAM → display → modem so inrush current never resets the SoC. The application processor loads and cryptographically verifies a 100–500 MB modem firmware blob before releasing the modem from reset. The RF receiver comes up in listening mode; the PA stays off.

Unlocks: a running modem with calibrated I/Q, but zero knowledge of time or frequency.

Stage 3 · Cell search

The UE scans the GSCN grid, correlates for one of 3 PSS sequences to win symbol timing, then resolves 1 of 336 SSS sequences to compute the 1008-way Physical Cell ID. PBCH carries the 24-bit MIB via polar coding at rate ≈1/15.

Unlocks: time, frequency, cell identity, and a pointer to SIB1.

Stage 4 · System information

Blind PDCCH decoding with SI-RNTI = 0xFFFF finds the grant for SIB1 on PDSCH. SIB1 is the first message that describes the uplink: UL ARFCN, initial UL BWP, RACH-ConfigCommon, PUSCH/PUCCH-ConfigCommon.

Unlocks: permission and parameters to transmit at all.

Stage 5 · Random access

A Zadoff–Chu preamble with a ~103 µs cyclic prefix arrives without any timing advance. The gNB measures its arrival time, returns a TA command plus the very first UL grant, and contention is resolved by echoing the UE identity in MSG4.

Unlocks: uplink synchronisation and a C-RNTI.

Stages 6–7 · RRC and NAS

RRC Setup configures bearers, BWPs, PUCCH/PUSCH, CSI and SRS. Piggybacked inside RRC Setup Complete, the NAS Registration Request carries a SUCI so the IMSI is never sent in clear. 5G-AKA gives mutual authentication and the K_gNB key hierarchy.

Unlocks: ciphered, integrity-protected signalling.

Stage 8 · PDU session

The SMF allocates an IP address and QoS flows (5QI, GFBR, MFBR); the gNB maps each QoS flow onto a Data Radio Bearer and configures SDAP accordingly.

Unlocks: an open data pipeline from app socket to UPF.

Stage 9 · The layer cake

SDAP marks QFI, PDCP does ROHC + ciphering + sequence numbering, RLC segments to the exact byte budget MAC offers, and MAC multiplexes SDUs and control elements into one transport block.

Unlocks: a transport block sized precisely for the grant.

Stage 10 · Getting permission

A 1-bit Scheduling Request on PUCCH says “I have data”. The grant that follows carries a BSR, which tells the gNB exactly how many bytes wait per logical channel group. DCI 0_0/0_1 then specifies PRBs, MCS, K2, RV, HARQ ID and TPC.

Unlocks: a legal time-frequency slot to transmit in.

Stage 11 · PUSCH chain

Sixteen deterministic transforms: CRC-24A, code-block segmentation, LDPC, rate matching, scrambling, modulation, layer mapping, optional DFT-spreading, precoding, RE mapping, DMRS/PT-RS, IFFT, CP, power control, DAC, PA.

Unlocks: radio waves.

Stages 12–13 · Control and sounding

PUCCH formats 0–4 scale from a 1-bit cyclic shift to 1706-bit polar-coded UCI. SRS sounds the uplink even with no data, enabling codebook precoding, reciprocity-based DL beamforming and frequency-selective scheduling.

Stages 14–16 · The three loops

HARQ (16 processes, LLR combining), link adaptation (outer-loop BLER target of 10 %), and timing advance maintenance — from 0.67 ms terrestrial range to 600 ms for NTN GEO in Release 17.

Stages 17–18 · gNB receiver

Per-antenna FFT, DMRS channel estimation, MMSE-IRC combining, Max-Log-MAP LLRs, descrambling, HARQ combining, LDPC belief propagation, CRC-24A check, then MAC/RLC/PDCP/SDAP reassembly into a GTP-U tunnel over N3 to the UPF.
I

Silicon to synchronisation

Before a single uplink bit exists, the UE must boot its modem, calibrate its radio, and find a cell in an unknown time-frequency universe.

Stage 1 · Hardware power-on

Pressing power triggers a strict rail sequence — not one event

Modem rail comes up last

On Snapdragon platforms the PMIC brings up the SoC first and only asserts the MSS enable line once the AP confirms the inter-processor bus is ready.

Firmware is the whole stack

That binary blob contains PHY, MAC, RLC, PDCP, RRC and NAS — the entire protocol stack ships as modem firmware, not OS code.

Three gates before release

Image loaded into protected memory → cryptographic signature verified → shared memory mapped. Only then does reset drop.

Stage 2 · Modem boot & RF initialization

A hard real-time OS, then a radio that is listening to nothing

RF front-end initialization path

Modem RTOS brings up three things

  • Task scheduler — hundreds of tasks, one set per protocol layer, with hard microsecond-scale priorities
  • Shared-memory ring buffers — QMI signalling plus zero-copy IP data to the AP
  • L1 DSP firmware — loaded into Hexagon internal SRAM to drive the RF hardware
Deterministic scheduling in microseconds, not milliseconds — a missed slot boundary is a lost transmission opportunity.

The modem is “alive” but blind

It does not know its carrier frequency, where OFDM symbols start, which frame it is in, or which of the 1008 cell identities is nearby. Cell search must solve all four.

Stage 3.3 · SSB structure

Four symbols × 240 subcarriers — click a symbol

Symbol 0 · PSS

127 subcarriers in the centre, guard bands either side. This is the only signal the UE can find with no prior knowledge, because m-sequence correlation works blind — no channel estimate required.

Symbol 1 · PBCH

The full 240 subcarriers carry polar-coded PBCH plus its own DMRS. PBCH DMRS also encodes part of the SSB index, which is how the UE learns which beam it just measured.

Symbol 2 · SSS in the middle

SSS takes the central 127 subcarriers; the 56 subcarriers above and below still carry PBCH. Nothing is wasted — the SSB is deliberately spectrum-frugal because it is broadcast constantly.

Symbol 3 · PBCH

The final PBCH symbol completes the 432 QPSK symbols carrying the 864 encoded bits of the MIB payload.

The asymmetry that defines stage 5

The UE now knows everything about how to transmit — frequency, bandwidth, power target, preamble set. What it still lacks is uplink timing and an identity. Only random access can supply those.

Stage 5 · Random access

Downlink-synchronised is not uplink-synchronised

The UE knows the gNB's timing. The gNB does not know the UE exists, how far away it is, or what to call it.

Problem 1 · Unknown propagation delay

Distance is unknown, so the delay is unknown. Without a timing advance the far UE's symbols land outside the near UE's cyclic prefix window → inter-symbol and inter-UE interference.

Problem 2 · No identity

Every future scheduling decision, scrambling sequence and PUCCH resource is keyed to a C-RNTI. The UE has none yet.

Stage 5.4–6 · Contention resolution & RRC setup

Two UEs, one preamble — step through the collision

MSG1 · collision happens invisibly

Preamble choice is random out of 64. Two UEs picking the same index in the same occasion produce a single detected correlation peak — the gNB cannot tell them apart, and does not need to yet.

MSG2 · one RAR, two believers

The RAR is addressed by RA-RNTI and echoes the preamble index. Both UEs match it, both apply the same timing advance, and both take the same temporary C-RNTI and the same uplink grant.

MSG3 · the actual contest

Both transmit on identical resources. The gNB decodes at most one — whichever wins the power/channel contest. Its RRC Setup Request carries a unique UE identity, and that identity becomes the tiebreaker.

MSG4 · resolution and RRC setup

MSG4 echoes the decoded identity. The matching UE promotes its temporary C-RNTI to a real one; the loser sees a foreign identity and restarts from MSG1. RRC Setup then configures SRB1, BWPs, PUCCH, PUSCH, CSI and SRS, and the UE replies with RRC Setup Complete on PUSCH — carrying the NAS Registration Request inside it.

State after MSG4

Uplink synchronised with a valid TA · C-RNTI assigned · SRB1 available · RRC connection established. Data bearers still require NAS registration.

Stage 7 · NAS registration and authentication

Mutual authentication before a single data byte

NAS messages pass transparently through the gNB between the UE and the AMF — the radio network relays but never interprets them.

K_AUSF → K_SEAF → K_AMF → K_gNB → K_UPenc
the key hierarchy that PDCP ciphering later consumes

SUCI, never IMSI

The UE presents a Subscription Concealed Identifier — the IMSI encrypted with the home network's public key — so a permanent subscriber identity is never sent in plaintext over the air. It also states the network slice it wants via requested NSSAI.

This request rides inside RRC Setup Complete, which means the first NAS message and the first SRB1 PUSCH transmission are the same event.

Optional identity exchange

If the AMF cannot resolve the UE from the supplied identifier — for example after a context loss — it explicitly asks for identity information before proceeding to authentication.

Challenge-response, both directions

The AMF fetches authentication vectors from the UDM in the home network and sends RAND and AUTN.

The USIM verifies AUTN — proving the network is legitimate, which is what makes this mutual authentication and blocks false base stations — then computes RES* from RAND and the secret key K that never leaves the card. The AMF compares RES* with its expected value.

Either 5G-AKA or EAP-AKA′ may be used.

Two security layers switch on

NAS security: ciphering with 128-bit NEA1 (SNOW 3G), NEA2 (AES-CTR) or NEA3 (ZUC), plus integrity protection on all subsequent NAS messages.

AS security: RRC Security Mode Command activates PDCP-level protection, so all radio-bearer traffic from this point is encrypted with keys derived from K_gNB.

A new pseudonymous identity

Registration Accept returns the 5G-GUTI, replacing SUCI for future signalling, along with the allowed NSSAI, the tracking area list and any mobility restrictions. The UE is registered — but still cannot send user data.

III

The uplink layer cake

One IP packet descends five layers before it becomes a transport block. Each layer solves exactly one problem the layer below cannot.

Stage 9 · User-plane protocol stack

Click a layer to see what it adds — and what it costs

Descending order = transmit path. The gNB executes the exact inverse, bottom-up.

Application

Produces IP packets with no awareness of radio conditions. Everything below exists to hide a fading, interference-limited, shared medium behind a socket.

IP / transport

An IPv4 + TCP header is 40 bytes. On a 60-byte VoIP payload that is 67 % overhead — which is precisely why PDCP header compression exists one layer down.

SDAP — new in 5G NR

A deliberately thin layer that did not exist in LTE. It marks each packet with the correct QoS Flow ID so the gNB can steer it to the right DRB.

Uplink SDAP header is a single byte — QFI (6 bits) plus RDI and RQI — and is added only when reflective QoS mapping is active. Otherwise no header at all.

PDCP — four jobs

ROHC squeezes 40-byte headers to 1–4 bytes once a flow context exists. Ciphering uses NEA1/2/3 with the PDCP-SN as the stream-cipher counter, guaranteeing no keystream reuse. Integrity adds a 32-bit MAC-I — on signalling bearers only, because it is too costly for high-rate data. Sequence numbering (12 or 18 bits) enables reordering and lossless handover.

RLC — fit the byte budget

MAC says “I can carry X bytes this TTI” and RLC segments the next PDCP PDU to exactly X. Three modes: TM (no header, used for CCCH and broadcast), UM (segmentation, no retransmission — streaming), AM (full ARQ for TCP-like reliability).

RLC ARQ is not HARQ: tens of milliseconds at RLC versus milliseconds at PHY.

MAC — the traffic manager

Multiplexes RLC PDUs from several logical channels plus control elements into one transport block, runs the 16 HARQ processes, issues scheduling requests and buffer status reports, applies timing advance and drives random access.

PHY — bits to waveform

Receives the transport block plus TBS, MCS, resource allocation, RV and NDI, then executes the sixteen-step PUSCH chain that occupies all of Part IV.
Stage 9.1–9.2 · SDAP and PDCP

Marking, compressing, encrypting, numbering

PDU structures

Why the PDCP-SN doubles as the cipher counter

Stream ciphers must never reuse a keystream. Using the sequence number as the counter guarantees every packet gets a unique keystream under the same key — semantic security for free, with no extra bits on air.

1 · Header compression (ROHC)

Tracks fields that barely change — source and destination IP and port are effectively constant within a flow — and transmits only what moved.

2 · Ciphering

128-bit NEA1 (SNOW 3G), NEA2 (AES-CTR) or NEA3 (ZUC), negotiated during NAS security setup, keyed from K_UPenc at the bottom of the key hierarchy.

3 · Integrity protection

A 32-bit MAC-I over the PDU, on signalling radio bearers only. Data radio bearers skip it: at multi-gigabit rates the cost outweighs the benefit.

4 · Sequence numbering and reordering

HARQ and RLC can deliver out of order. PDCP buffers and reorders before handing packets up, and during handover PDCP data forwarding prevents loss.

Stage 9.3 · Radio Link Control

Three modes, because reliability is not always worth the delay

TM · Transparent

No header at all

Used for BCCH system-information broadcast and CCCH (RRC Setup Request). No segmentation, no retransmission — the message must fit as-is.

UM · Unacknowledged

Segment, never retransmit

RLC-SN plus segmentation. Chosen for streaming video and voice where a late packet is worthless; TCP or the codec absorbs loss.

AM · Acknowledged

Full ARQ

The receiver ACK/NACKs each PDU and the sender retransmits NACKed segments — recovering losses far faster than TCP could.

Stage 9.4–9.5 · MAC and the PHY handover

One MAC PDU is one transport block

MAC PDU layout

Control elements that steer the uplink

  • BSR — bytes waiting per logical channel group; this is what actually triggers a grant. Short BSR covers one group, long BSR all four.
  • PHR — power headroom: the gap between P_CMAX and current transmit power, so the scheduler never grants more bandwidth than the UE can power.
  • TA command — applied immediately on reception.

NDI is a single bit of enormous consequence

It is the only thing distinguishing “send something new” from “send the same block again with different parity”. Misread it and the HARQ buffer corrupts.

SR is transmitted by presence or absence — the UE simply does not transmit when it has nothing to say. If no grant follows within the window, it retries; after sr-MaxTransmissions (up to 8) failures it declares SR failure and falls back to RACH.

Frequency domain resource assignment

Either a bitmap of resource-block groups or a start-and-length encoding, depending on resource allocation type. With transform precoding enabled the allocation must be contiguous.

Time domain resource assignment

Four bits index the PUSCH-TimeDomainAllocationList, which yields K2 — how many slots after the DCI the PUSCH is transmitted — plus the start symbol and length. This is what makes the grant a future contract rather than an immediate command.

Modulation and coding scheme

Five bits index an MCS table giving modulation order Q_m and target code rate R. Together with the PRB count this determines transport block size through the TS 38.214 lookup.

New data indicator

A toggle, not a flag. Compared against the last value for this HARQ process: toggled means fetch a new transport block from MAC, unchanged means retransmit what is already in the HARQ buffer.

Redundancy version

Selects the circular-buffer starting offset in the cycling order 0 → 2 → 3 → 1, which is what turns retransmissions into incremental redundancy rather than plain repetition.

HARQ process number

Four bits address one of 16 parallel processes. Sixteen outstanding transmissions are what keeps the pipeline full despite an ~8 ms HARQ round-trip.

TPC command

Two bits mapping to −4, −1, +1 or +3 dB. This is the closed-loop term f(i) in the power control equation, nudged slot by slot as the gNB watches received SINR.

Frequency hopping flag

Enables intra- or inter-slot hopping so a narrowband allocation samples different parts of the band, buying frequency diversity for coverage-limited UEs.

What DCI 0_1 adds

BWP indicator (switch among up to 4 uplink BWPs), antenna ports and SRS resource indicator for non-codebook operation, number of MIMO layers, DMRS ports, CSI request, code-block-group transmission indicator and PT-RS/DMRS association. DCI 0_0 stays deliberately small and robust as the fallback.

Stage 11 · Physical uplink shared channel

Sixteen transforms from bits to radiation — click any step

1 · Transport block CRC

The MAC PDU arrives as a transport block. A CRC is appended so the receiver can verify the whole block: CRC-24A when the TB exceeds 3824 bits, otherwise CRC-16.

g(x) = x²⁴+x²³+x¹⁸+x¹⁷+x¹⁴+x¹¹+x¹⁰+x⁷+x⁶+x⁵+x⁴+x³+x+1

This CRC is what ultimately drives HARQ ACK or NACK.

2 · Code block segmentation

LDPC has a maximum block size — 8448 bits for base graph 1, 3840 for base graph 2. Larger transport blocks are split into C equal code blocks, each receiving its own CRC-24B.

Per-code-block CRC is what makes code-block-group retransmission possible: only the failing pieces need to be sent again.

3 · LDPC encoding

Each code block is encoded with a quasi-cyclic LDPC code built by expanding a compact base graph with a lifting size Z (2…384, 51 permitted values). BG1 targets large blocks and high rates; BG2 targets small blocks and low rates.

LDPC replaced turbo coding in NR because belief-propagation decoding parallelises far better at multi-gigabit rates.

4 · Rate matching

The encoder output is written into a circular buffer; the transmitter reads exactly as many bits as the granted resources allow, starting at the redundancy-version offset. Reading less than the full buffer punctures parity; reading past the end repeats bits.

The first 2Z systematic bits are always punctured — they are recoverable from parity, so puncturing them costs almost nothing.

5 · Code block concatenation

The rate-matched code blocks are concatenated back into a single codeword whose length exactly matches the number of available bits in the grant — modulation order × layers × available REs.

6 · Scrambling

The codeword is XORed with a length-31 Gold sequence initialised from the UE's RNTI and the data scrambling identity. This randomises the bit stream so that long runs of identical bits cannot create spectral spikes, and so neighbouring cells' interference looks like noise rather than structure.

7 · Modulation mapping

Bits become complex symbols: π/2-BPSK, QPSK, 16-QAM, 64-QAM or 256-QAM (Q_m = 1, 2, 4, 6, 8). Each constellation is normalised to unit average power — 1/√2, 1/√10, 1/√42, 1/√170 — so power control operates independently of the chosen order.

8 · Layer mapping

For spatial multiplexing the symbol stream is de-interleaved across up to 4 uplink layers. Each layer will be sent through a different effective spatial channel, multiplying throughput when the channel matrix has sufficient rank.

9 · Transform precoding

Optionally an M-point DFT is applied across the allocated subcarriers, converting CP-OFDM into DFT-s-OFDM. This spreads each symbol across the whole allocation, producing a single-carrier-like waveform with dramatically lower PAPR — the cell-edge coverage tool.

10 · Precoding

Layers are mapped to physical antenna ports through a precoding matrix. In codebook mode the gNB signals the matrix index in the DCI; in non-codebook mode the UE derives it itself from downlink measurements and SRS feedback.

11 · Resource element mapping

Symbols are written into the time-frequency grid at exactly the PRBs and symbols the grant specified, skipping any RE reserved for DMRS, PT-RS or other configured signals. A one-RE offset here destroys the whole transmission.

12 · DMRS and PT-RS insertion

Known pilot symbols are inserted so the receiver can estimate the channel. DMRS type 1 uses 6 REs per PRB and supports up to 4 ports; type 2 uses 4 REs and supports up to 6. At mmWave, PT-RS is added to track phase noise.

13 · IFFT

The frequency-domain grid becomes a time-domain waveform. Typical sizes: 2048 points at 15 kHz spacing over 20 MHz (30.72 Msps), or 4096 points at 30 kHz over 100 MHz (122.88 Msps). Orthogonality of the subcarriers is created here, mathematically, for free.

14 · Cyclic prefix insertion

The tail of each symbol is copied to its front. Any echo arriving within the CP window still sees a cyclically-shifted version of the same symbol — which in the frequency domain is merely a phase rotation, correctable by a single complex multiply per subcarrier.

15 · Power control

The transmit power is computed from allocation size, path loss, a fractional compensation factor α, the modulation-dependent offset Δ_TF and the closed-loop accumulator f(i) — then clipped at P_CMAX.

16 · DAC, PA and antenna

A 10–14 bit DAC produces the analogue baseband, mixers upconvert it, and a power amplifier with 30–40 dB gain drives the antenna. The PA is the single largest consumer of battery in an active uplink — which is why every PAPR trick matters.

Why two CRCs

CRC-24A protects the transport block end to end and decides HARQ feedback. CRC-24B protects each code block individually, which is what lets the receiver identify which segment failed.

Why segment at all

LDPC decoder hardware is built around a maximum block length. Segmentation keeps the decoder tractable and lets code blocks be decoded in parallel — essential for gigabit throughput.

Base graph selection

BG2 is chosen for small blocks (≤ 292 bits) or low code rates (≤ 0.25); BG1 otherwise. BG1 is a 46 × 68 base matrix with k_b = 22, supporting rates 1/3 to 8/9; BG2 is 42 × 52 with k_b = 10, rates 1/5 to 2/3.

Systematic puncturing

The encoder output starts with the information bits themselves, but the first 2Z systematic bits are always punctured before transmission. Their information survives in the parity bits, so the loss is negligible while the saved airtime is not.

Decoding side

Belief propagation passes soft messages between variable and check nodes, typically converging in 10–50 iterations. The CRC is checked between iterations so decoding can stop early — a significant energy saving at good SINR.

Rate is not fixed by the code: the same encoder output feeds rate matching, which is where the actual transmitted rate is chosen.
Step 4 · Rate matching and HARQ redundancy

Choose a redundancy version and a read length

Redundancy version
Granted length 32 % of buffer

The circular buffer

Encoder output is written once. Each transmission reads a window from a different starting point — 0, 1/4, 1/2 or 3/4 of the buffer for RV 0, 2, 3 and 1 respectively.

Incremental redundancy

Because successive RVs read different parity, a retransmission delivers new information rather than a copy. The decoder combines LLRs, effectively lowering the code rate with every attempt.

Why RV 0 comes first

RV 0 begins at the systematic region, so a single transmission at a reasonable SINR usually decodes on its own. The remaining RVs exist to rescue the roughly 10 % that do not.

Steps 8 & 10 · Spatial processing

One stream becomes four, then becomes antenna signals

Codebook mode

The gNB measures SRS, picks a precoder from a standardised codebook, and signals the index (TPMI) in the DCI. Low feedback overhead, predictable behaviour, slightly suboptimal.

Non-codebook mode

The UE derives its own precoder from downlink measurements, exploiting reciprocity in TDD. Better matched to the true channel, at the cost of UE complexity and reliance on calibration.

Rank is a scheduling decision

More layers only help when the channel is rich enough to separate them. In a line-of-sight or low-SNR uplink, rank 1 with all power in one beam beats rank 4 with power split four ways.

Step 9 · Transform precoding and the PAPR problem

Toggle the waveform and watch the envelope — this is a battery decision

Waveform
PAPR ≈ 10–12 dB — amplifier must back off

Why OFDM peaks

Hundreds of independently-modulated subcarriers occasionally align in phase. The sum is Gaussian-like, so rare but large peaks are inevitable.

What the DFT does

An M-point DFT before the IFFT spreads every symbol across the whole allocation. The result behaves like a single-carrier signal: nearly constant envelope.

The payoff

Backing off less means real transmitted power is higher for the same battery drain — several dB of uplink coverage, exactly where cell-edge users need it.

The cost

Only single-layer transmission, and frequency-selective scheduling is weakened because every symbol now occupies the entire allocation.

DMRS generation

A pseudo-random QPSK sequence the receiver already knows — dividing the received value by it gives the channel estimate.

Density is a trade

More additional positions track fast fading better but steal REs from data. High mobility wants 2–3 positions; a stationary UE is fine with front-loaded DMRS only.

PT-RS at mmWave

Oscillator phase noise at 28 GHz rotates the constellation within a single symbol. PT-RS samples that rotation continuously, recovering 2–5 dB for high-order modulation in FR2.

Why the copy works

A cyclic shift in time is a phase rotation in frequency. So an echo that lands within the CP leaves each subcarrier merely rotated — correctable by one complex multiply per subcarrier, the entire reason OFDM beat single-carrier equalisation.

CP lengths

  • Normal CP: 144 samples ≈ 4.69 µs — roughly 1.4 km of path difference
  • Extended CP: 512 samples ≈ 16.67 µs — for extreme delay spread
  • The first symbol of each half-subframe uses a longer CP to absorb timing drift

The overhead

The CP carries no new information — about 7 % of airtime is spent transmitting a copy of something already sent. That is the price of turning a convolution into a multiplication.

Five knobs decide how loudly the UE speaks

Fractional path loss compensation

α = 1 fully compensates path loss: every UE arrives at the same power, but cell-edge UEs shout and pollute neighbours. α < 1 deliberately under-compensates — edge users arrive weaker, and total system capacity rises.

Closed loop f(i)

TPC commands in the DCI apply δ ∈ {−4, −1, +1, +3} dB, accumulating into f(i). The gNB corrects whatever the open-loop estimate got wrong — mismatched calibration, sudden shadowing, interference changes.

+23.0 dBmwithin P_CMAX

P_CMAX is +23 dBm for a class 3 UE (+26 dBm for some bands). When the computed value exceeds it the UE clips, reports a negative power headroom, and the scheduler must shrink the allocation instead.

Stage 12 · Uplink control information

Five formats, chosen by payload size and coverage — click one

What UCI carries

  • HARQ-ACK — feedback for downlink transport blocks
  • SR — request for an uplink grant
  • CSI — CQI, PMI, RI, and beam reports (CRI / L1-RSRP)

Format 0 · sequence selection

1–2 bits over 1–2 symbols. There is no DMRS at all — information is conveyed by which of 12 cyclic shifts of a base sequence is transmitted. The receiver correlates against all 12 and picks the strongest.

Extremely efficient in resources, but non-coherent detection costs roughly 2–3 dB relative to Format 1. It is the right choice when latency and resource cost matter more than link budget.

Format 1 · long, orthogonal cover codes

1–2 bits spread over 4–14 symbols, alternating DMRS and data symbols so channel estimation and coherent detection are possible.

An orthogonal cover code multiplies each symbol by a phase rotation:
w_n[l] = exp(j2πnl/N)
Different UEs use different n, so they share the same time-frequency resource and separate perfectly at the receiver — provided their channels stay coherent across the OCC span.

Format 2 · Reed–Muller coded

Up to 11 bits over 1–2 symbols with QPSK modulation and DMRS on every third subcarrier. The short Reed–Muller block code is optimal at these tiny payload sizes, where LDPC or polar overhead would dominate.

Format 3 · polar coded

Up to 1706 bits — enough for full multi-panel CSI reports with wideband and subband PMI. Uses polar coding, optionally with DFT-s-OFDM for lower PAPR at cell edge.

Format 4 · spread multiplexing

Medium payloads with a spreading factor of 2 or 4 applied in the frequency domain, letting 2 or 4 UEs share one PRB. A capacity tool for cells with many low-rate control users.
Research context · PUCCH Format 1 in non-terrestrial networks

The OCC assumption that LEO satellites violate

Coherent OCC despreading requires a static phase

Why LEO is different

  • Satellite ground speed ~7.5 km/s → Doppler shifts of tens of kHz
  • Pre-compensation from ephemeris removes the bulk, but a residual remains
  • The residual is time-varying within the 4–14 symbol PUCCH span, which is exactly what OCC assumes constant

A learned receiver instead of a fixed despreader

Rather than assuming coherence, the receiver can be trained to recognise the structure of the residual phase evolution.

Feature representation: a 28 × 14 residual Doppler phase vector — phase evolution across symbols and resources — fed to a Transformer-based PUCCH receiver.

Why a Transformer fits this problem

  • Self-attention models dependencies across the whole symbol span, not just between adjacent pilots
  • It can learn the deterministic component of orbital Doppler rather than treating it as noise
  • Detection and phase tracking become one joint estimator instead of two cascaded, mismatched stages

Stage 14 · HARQ for the uplink

Step a transport block through failure and recovery

Asynchronous uplink HARQ

Unlike LTE's synchronous uplink, NR uplink HARQ is asynchronous: retransmissions happen whenever the gNB schedules them, identified explicitly by HARQ process ID in the DCI. There is no fixed 8 ms grid to obey.

Soft combining is the whole point

The receiver adds LLRs from both attempts rather than discarding the first. Combining RV 0 and RV 2 produces a genuinely lower-rate code — far stronger than simply repeating the same bits twice.

Code-block-group retransmission

Because each code block carries CRC-24B, only the failing code-block groups need to be resent. On large transport blocks with a single bad segment this saves substantial airtime.

Why 16 processes

A single stop-and-wait process would idle for the whole round trip. With up to 16 processes the UE always has something to send, so throughput is decoupled from feedback latency. Each process holds an independent soft buffer — which is exactly why HARQ memory is a real cost in UE silicon.

What the gNB measures

SRS and DMRS give SINR estimates; HARQ ACK/NACK statistics give an outer-loop correction. The target is roughly 10 % BLER on the first transmission — deliberately not zero, because HARQ recovers the rest and a lower target would waste spectral efficiency.

Uplink-specific constraints

Link adaptation must also respect the power headroom report. A UE at the cell edge may have excellent measured SINR on a narrow allocation yet be unable to power a wider one — so the scheduler trades bandwidth against power, not just MCS against SINR.

  • The gNB then sends 6-bit relative TA commands as a MAC CE
  • A timeAlignmentTimer expiry means the UE must redo RACH — uplink sync is considered lost

NTN breaks the assumption

Rel-15 TA covers roughly 667 µs — ample for a 15 km terrestrial cell, hopeless for satellites. Rel-17 NTN extends the range to about 600 ms and adds UE-side pre-compensation from GNSS position plus broadcast satellite ephemeris.

Also affected

Long propagation forces changes to HARQ timing (K1/K2 offsets), the RA-ResponseWindow, and the HARQ feedback-disabled mode — because waiting for an ACK from GEO would stall the pipeline entirely.

Channel estimation is the crux

DMRS REs give point estimates; everything between them is interpolated in frequency and time. Estimation error propagates directly into demodulation error, which is exactly why DMRS density is a scheduling decision rather than a constant.

W = (H HH + Rint)−1 H
MMSE-IRC: interference covariance Rint lets the receiver null spatially-coloured interference from neighbouring cells

Soft information, not decisions

The demodulator emits log-likelihood ratios rather than hard bits. LDPC belief propagation needs that confidence information — handing it hard bits would throw away several dB of coding gain.

Early termination checks the CRC between iterations and stops as soon as it passes, cutting decoder energy substantially at good SINR.

Above the physical layer

  • MAC — parse subheaders, split SDUs, act on BSR / PHR control elements
  • RLC — reassemble segments, run ARQ, deliver in order
  • PDCP — decipher, verify integrity, decompress headers, reorder
  • SDAP — read QFI, map to the correct QoS flow

Then GTP-U encapsulation carries the packet over N3 to the UPF, which strips the tunnel and routes it to the internet.

Three ideas that recur everywhere

  • Every layer solves one problem the layer below structurally cannot — which is why the stack is deep rather than wide.
  • Redundancy is spent, not given — CRC, LDPC, RV cycling and HARQ each buy reliability at a measured cost in spectral efficiency.
  • The uplink is power-limited — PAPR, α, PHR and DFT-s-OFDM exist because the UE's battery, not the spectrum, is the binding constraint.
